# IS-OTK-ELMA
Информационная система Отдела Технического Контроля (ОТК).

## 🛠 Стек
- Python 3.10+
- PyQt6 (GUI)
- MySQL / MariaDB (PyMySQL)

## 🚀 Быстрый старт
1. Клонируйте репозиторий: `git clone https://github.com/slavkkinns-ux/IS-OTK-ELMA.git`
2. Создайте виртуальное окружение: `python -m venv venv`
3. Активируйте его и установите зависимости: `pip install -r requirements.txt`
4. Скопируйте `config.example.py` в `config.py` и заполните данные для подключения к БД.
5. Выполните скрипт `sql/create_db.sql` в вашей базе данных.
6. Запустите приложение: `python main.py`

## 📁 Структура проекта
- `main.py` - Точка входа и управление циклом авторизации
- `ui/` - Компоненты пользовательского интерфейса
- `styles/` - QSS файлы тем оформления
- `db.py` - Базовый класс для взаимодействия с БД (планируется рефакторинг в репозитории)
- `session.py` - Управление сессией текущего пользователя
